# 注意力机制 · 设计记录

> 这是示例 deck 的设计决定和来龙去脉，也是一份“设计文稿该写到什么程度”的范例。它不是风格模板：别的主题应该从自己的内容里找到自己的意象，而不是套用暗场。

## 意象

注意力机制让模型第一次真正“看见”上下文：在一句没有规律的话里，找到 it 指的是谁。**黑夜里出现了光，光照亮了规律。**

整套演示由此推导：

- **一间暗室**：暖炭色的底（`17151A`），极细的颗粒，四角压暗。没有纯平的近黑。
- **注意力就是光**：唯一的颜色是琥珀色的热度色阶，越受关注越亮。每页的视觉中心有一束柔和的光（`k.light`），翻页时光随 Morph 移到下一个重点。
- **母题**：方格。注意力矩阵、向量、进度标记，都是同一种格子。
- **真实的例子**：例句以真正的 prompt 出现：等宽字体、提示符、光标，S02 中逐词打出。

## 设计系统（`theme.js`）

| 角色 | 字体 | 说明 |
|---|---|---|
| 标题 | 宋体（SimSun），字距 +5–8% | 电影片头的感觉；只用于大字号，小字笔画会发虚 |
| 大号西文、Q/K/V、大号数字 | Palatino Linotype | 古典衬线，与宋体同属书卷气；数字是等高数字 |
| 小字、标签、页码 | Franklin Gothic Medium | 笔画稍重，暗底上投影时小字不会糊 |
| 正文 | 微软雅黑 | |
| 例句（prompt） | Consolas | 像输入给模型的一句话 |

结构层：右上角章节标记、左下角进度格、右下角页码；S03 的旗标标注（竖线，和斜向的弧线区分开）；S04 的尺寸线。

## 决定与被否掉的方案

1. **方向**（`history/1-directions.png`）：比较了三个方向。A 纸与墨：下限高，但不适合每个主题。B 暗场热图：被选中，最贴合“光照亮黑夜”。C 符号海报：钴蓝和主题没有关联，第二页又换成白底，风格不连贯。
2. **背景**（`history/2-background.jpg`）：最初的纹理有低频斑驳，看起来像灰尘。改成平滑的光、极细的颗粒、四角压暗。
3. **光**：先是烤进背景图的光（不能移动）；然后改成椭圆形状（PowerPoint 里能看到椭圆的边缘）；最后是正方形承载、边缘完全透明的漫反射光，可以随 Morph 移动。
4. **字体**（`history/3-typography.png`）：苹方加 Helvetica 是系统默认的组合，没有个性。在电影片头、精密仪器、人文书卷三套方案里选了电影片头；例句先试了 Hoefler 斜体，像书页上的引文，没有代入感，最后改成 prompt 的样子。
5. **空页**：最初的 Q/K/V 页只有三个字母，显得偷懒。改成把机制画出来的图解，并写进了规范（`anti-ai.md`「伪极简」）。

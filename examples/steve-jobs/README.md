# Steve Jobs 的一生 · 空房间

23 页，原生可编辑的 PowerPoint。

![全套 23 页](renders/_contact.png)

```bash
node engine/make.js examples/steve-jobs     # 构建 + QA + 渲染全部 23 页 → out/steve-jobs-life.pptx
```

## 意象

整套演示是 1982 年他那间几乎空着的客厅：一面墙、一块地板、一扇窗。

- **每页只放一件东西**：父亲的篱笆、一对字母、Apple I、Apple II、Macintosh、NeXT 立方体、iPod、iPhone。
- **每件东西按真实尺寸画**：Mac 128K 按 244 × 345 mm，屏幕按 512 × 342 像素；iPhone 按 61 × 115 × 11.6 mm。
- **画出它怎样工作**：Mac 的屏幕上，同一个词用等宽和按比例两种字距各排一遍；iPod 画出滚轮的三下点击。
- **两种声音**：墙上写的话用衬线（Songti SC / Hoefler Text），事实、年份、标签用无衬线。

**太阳是时间。** 窗外的阳光从封面的清晨走到最后一页的黄昏，他的一生是一天。光斑和影子由 `room.py` 按房间的相机、窗和每件物件的真实尺寸算出，物件和它的影子永远对得上。

| 页 | 时刻 | |
|---|---|---|
| S01 | 清晨 | 名字落在窗光里 |
| S10–S11 | 正午 | Mac 和它机箱里的签名 |
| S12 | 阴天 | 30 岁被开除，没有太阳 |
| S20 | 金色时刻 | iPhone，全片最强的光 |
| S23 | 最后的光 | 他做的东西站成一排 |

**蓝线只有一个意思：回头才看得见的联系。**地板上那条缝是他的生命线；到最后一页，9 条线全部出现。

## 目录

| 文件 | 内容 |
|---|---|
| `slides/` | 23 页，每页一个文件，含演讲者备注 |
| `objects/` | 每件物件一个文件：真实尺寸 + 画法 |
| `room.json` · `rooms/` · `room.py` | 房间几何、每页的太阳；`python3 room.py S10` 重算一页的光（需要 numpy、scipy、Pillow） |
| `theme.js` · `parts.js` | 设计令牌与共享部件 |

## 已知限制

- 预览由 LibreOffice 渲染，不能播放 Morph 和页内动效；跨页 Morph 要在 PowerPoint 里放映确认。
- 阳光是每页一张生成的透明图片，在 PowerPoint 里不能当形状编辑。
- 字体全部是 macOS 系统字体；在 Windows 上播放请用 PDF。
- 物件按公开的产品外形与尺寸原生绘制，不使用任何商标和照片；S11 的签名是程序生成的示意笔迹。

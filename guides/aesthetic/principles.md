# 设计原则

> 何时读：写设计文稿时。制作阶段只在拿不准取舍时回来查优先级。

演示文稿不是加了美化的 Word 文档，而是以视觉为主要语言的讲述媒介。本项目服务**演讲者主导**的演示：画面负责视觉解释、关键提示和必要证据；展开说明交给口头讲解和演讲者备注。

## 三条核心原则

**1. 内容驱动。** 流程是“理解内容 → 提炼一句核心信息 → 选择表达方式 → 构图 → 编排动态”，而不是“选模板 → 填内容 → 加装饰”。整套演示统一的是设计语言，不是页面布局。

**2. 视觉优先。** 普通内容页由图像、图解、模型、图表承担表达，文字只负责提示、标注、强调。公式、定义、代码例外：它们必须以符号呈现，准确和可读优先。目标不是消灭文字，而是不让文字去做视觉能做得更好的事。

**3. 动态增强。** 有时间顺序、因果、状态变化、空间结构的内容，优先用连续的页面变化（Morph）来解释。动效要回答“发生了什么、为什么、谁和谁有关”，不为炫技而动。

## 取舍优先级

冲突时按顺序取舍。低优先级不是可以忽略，而是让位。

| 级 | 原则 | 例子 |
|---|---|---|
| P0 | 准确 | 不为美观改变真实的逻辑关系、删掉必要条件或伪造数据 |
| P1 | 内容驱动 | 统一版式和内容特性冲突时，用为内容定制的构图 |
| P2 | 一眼看懂 | 复杂动画降低理解效率时，用简单的方式 |
| P3 | 视觉优先 | 能画出来的不写出来 |
| P4 | 美感 | 构图、字体、留白、比例 |
| P5 | 统一 | 整套共享同一种设计语言 |
| P6 | 动态质量 | 空间连续性、节奏 |
| P7 | 装饰 | 最后考虑；有疑问就删 |

## 七个审美标准

- **秩序**：每个元素的位置、尺寸、间距都能说出依据（网格、基线、对齐关系）。打破网格要有意为之。
- **呼吸**：留白是构图的一部分。主体周围留足空间，不填满画面。
- **统一**：字体、颜色、线条、图片处理、边距、动画节奏保持一致；每页的构图可以各不相同。
- **层次**：观众应在一秒内知道先看哪里。靠尺寸、对比、位置、色彩、出现顺序拉开层级，不能所有元素一样重。
- **融合**：图片属于画面，而不是贴在画面上（见 `imagery.md`）。
- **节奏**：在页与页之间交替安静与强烈、全景与特写、浅色与少量深色，安排高潮和换气。
- **精致**：高级感来自细节之间的协调：字重、字距、线宽、色温、间距、动画速度。它不来自效果的堆积。

## 最终检验

- **单页**：遮住大部分文字，观众仍能从视觉对象看出这一页在讲什么；文字回来后，理解变得更精确。
- **整套**：把所有页缩成缩略图排在一起，即使不读内容，也能感到这是一套完整、协调、有节奏的作品。

> Content determines form. Visuals carry meaning. Motion reveals understanding. Consistency without repetition. Simplicity without emptiness. Beauty serves clarity.

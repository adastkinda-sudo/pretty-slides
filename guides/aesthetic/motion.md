# 动态与转场

> 何时读：设计文稿规划动态时；制作 Morph 序列时。

## 原则

- 动态用来解释**顺序、因果、状态变化和空间关系**。没有这些，就不动。
- 首选 **Morph（平滑切换）**：把一个动作写成**前后两页的差异**。同一个对象在两页上用同一个名字，PowerPoint 会自动补间位置、大小、颜色和文字。
- 风格要统一：整套用一种默认转场（通常是 `fade` 或无），Morph 只用在有连续性的地方。
- 观众要能追踪：一次只让一两个对象发生显著变化；其余保持不动。

## 用 Morph 做渐进展示

本引擎不生成页内的逐项动画（“单击后出现”）。逐步展示的做法是**拆成几页，用 Morph 串起来**。这也是更电影化的做法：

1. S05：完整结构的第一个状态（例：只有 Q、K、V 三个字母）。
2. S06：同样的对象，改变位置或大小，加入新的元素（例：Q 和 K 靠拢，公式出现）。`transition: 'morph'`。
3. S07：继续推进……

规则：

- 要延续的对象在每一页上都用 `name: 'q'` 这样的稳定名字（引擎会写成 `!!q`，这是 PowerPoint 强制配对的命名方式）。
- 文字内容变了也可以配对；PowerPoint 会做字符级的过渡。
- 新出现的对象淡入，消失的对象淡出。不需要额外处理。
- 镜头推近：同一张图或同一个结构在下一页放大到局部，就是“zoom in”。
- 一个序列通常 2–4 页。在 `design.md` 的节奏表里把它们标成同一个序列。

## 转场取值

在幻灯片模块里写 `transition`：

| 值 | 用途 |
|---|---|
| `'none'` | 直接切换（封面通常用这个） |
| `'fade'` | 默认的温和过渡 |
| `'morph'` | 与上一页有共享对象时 |
| `{ type: 'morph', duration: 1600 }` | 指定时长（毫秒）。默认 Morph 1200，fade 600 |

theme 的 `transition` 是整套的默认值。

## 验证

- LibreOffice 预览**不能**播放 Morph。静态渲染只能检查每一页的起始和结束状态。
- Morph 的实际效果必须在 PowerPoint 里放映检查。交付时告诉用户哪些页面用了 Morph，请他们在 PowerPoint 中放映确认。未经确认的，报告为“未验证”。
- Keynote 打开 pptx 时 Morph 会退化为“神奇移动”或淡入淡出。

## 禁止

文字从四面八方飞入、旋转、弹跳、与内容无关的缩放、所有元素同时运动、每页换一种转场、过长的动画。

# 色彩

> 何时读：设计文稿里确定色板时；样张反馈涉及颜色时。

## 原则

- **浅色为主，克制，有语义。** 背景用暖白、米白、浅灰之类，不必是纯白。少量深色页作为节奏变化。
- **一种强调色。** 强调色只落在每页最重要的那个东西上，面积通常是页面的 2–10%。一套演示里，强调色代表的意思要始终一致（例：始终表示“当前讨论的对象”）。
- **中性色做层级。** 用 3–4 级灰（ink / graphite / stone / hairline）区分主文字、次文字、标注和线条，而不是靠多种颜色。
- **数据和图片可以更丰富**，但数据图表的系列色仍然来自主题：重点系列用强调色，其余用灰。
- **对比度**：小于 24pt 的文字与背景对比 ≥ 4.5:1；24pt 及以上 ≥ 3:1。投影会损失对比度，宁可深一点。`make.js` 会自动检查。

## 色板配方（起点，按主题调整）

每套都是：背景 / 次背景 / 主文字 / 次文字 / 标注 / 细线 / 强调 / 深色页。标注色（stone）已调到在 paper 上满足 4.5:1；放在 paperDeep 上的小字改用 graphite。

**选配方 ≠ 设计完成。** 强调色应该从主题里找：讲古建筑可以用朱砂，讲海洋可以用深海蓝，讲某个机构就用它的标识色。改动配方后，检查标注色的对比度。

## 深色页

- 只在有目的时使用：章节转换、核心结论、视觉高潮、需要强对比的图像。一套里通常 ≤ 15%。
- 深色页的文字色要单独定义（`nightText`、`nightMuted`），不能直接复用浅色页的灰。

## 禁止

- 彩虹分类色、霓虹色、高饱和渐变。
- 同一种语义在不同页面里用了不同颜色。
- 为了“丰富”而加颜色。

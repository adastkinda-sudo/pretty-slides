# 去 AI 味

> 何时读：设计、样张、成稿、修改，每一步都读。

AI 生成的幻灯片一眼就能认出来，原因不是“丑”，而是**没有一页是为它自己的内容设计的**。下面是三种最常见的失败方式。前两种容易识别，第三种最隐蔽，而且我们自己的流程也可能制造它。

## 一、通用部件

用一套通用部件去填任何内容：卡片、图标、色带、编号圆圈、要点框。这些部件让每一页都“看起来像幻灯片”。

下表是**信号，不是禁令**。看到它们时，先问一句“这里真的需要它吗”；确实有内容上的理由，就在 `design.md` 里写明并使用。

| 信号 | 为什么常常不对 | 通常更好的做法 |
|---|---|---|
| **卡片网格**：3–4 个圆角卡片，各配图标、小标题、两行字 | 把不同性质的内容压成同一形状；卡片本身不携带意义 | 找到条目之间真实的关系（顺序、层级、对比、因果），把关系画出来；确实是并列的，用对齐的排版分栏 |
| **图标当项目符号**（灯泡、齿轮、火箭、对勾） | 装饰性的同义反复 | 用编号、字重、位置区分。图标就是内容本身（界面、设备、真实符号）时才用 |
| **每页顶部标题栏 + 彩色下划线或色块** | 模板感最强的来源 | 标题位置随构图变化；标题写成一句判断；有的页不需要标题。标签字号的导航框架不在此列（见 `composition.md`） |
| **渐变、发光、玻璃拟态、投影** | 用效果代替结构；投影时还会发灰 | 平涂颜色；层次靠尺度、明暗和空间 |
| **一切都居中对称** | 居中常常是“没做决定” | 非对称构图；单一焦点的页面才居中 |
| **等分**：三栏一样宽，两图一样大 | 没有主次 | 一个主体，其余从属 |
| **填空的装饰**：角落的点阵、斜线、几何色块、波浪 | 与内容无关 | 删掉；想让页面更丰富，用承载信息的结构层（`composition.md`） |
| **每个要点一种颜色** | 颜色失去语义 | 颜色要么有固定含义，要么是整套视觉语言的一部分 |
| **编号圆圈、KPI 卡片、徽章、标签胶囊** | 仪表盘部件，与讲述无关 | 数字直接用字体处理，大而不加框 |
| **“核心要点”框、结论色带** | 把结论装进盒子，反而削弱了它 | 让结论本身成为页面上最大的那句话 |
| **每页都是“小标签 + 大标题 + 副标题”** | 排版公式化 | 不同任务的页面用不同的文字结构 |
| **长的项目符号列表** | 文字在做视觉的工作 | 拆页、渐进展示，或者把关系画成图 |
| **emoji、剪贴画、3D 小人、AI 生成的“科技感”插图** | 廉价，与内容无关 | 真实的图片、原生绘制的图解，或者不用图 |
| **空话**：“赋能”“助力”“全面提升”“深度解析” | 内容空洞，设计跟着显得假 | 具体的名词、数字、例子；标题写成完整的判断 |
| **层级混乱**：字号和粗体太多 | 看不出先看哪里 | 少数几个对比强烈的层级 |

## 二、伪极简

避开了通用部件，很容易滑向另一头：页面很“干净”，却给人偷懒的感觉。

判断标准不是留白有多少，而是**这一页的任务和它展示的东西是否对得上**。论断页配大面积留白是对的；讲解机制的页面只放三个名词，就是空洞。示例里，这两种页面的着墨面积几乎一样（1.7% 对 2.2%），观感却完全不同。

症状：

- 讲解页上只有名词、字母或短语，没有任何表达关系的图形。
- 主角太小，或者三个同样大小的元素等距排开，没有主角。
- 留白被切成几条均匀的缝，而不是集中成一大块。
- 丢掉了贯穿的例子：前一页刚讲过具体的例子，这一页又回到抽象。

改法：讲解页要有一张图来承担机制，名字只是图上的标签。图的形式见 `data-and-diagrams.md` 的“图解配方”；用贯穿的例子把图填实；复用整套的母题；让图大起来。

引擎会检查：标为 `rhythm: 'dense'` 的页面如果没有任何图形对象，QA 判为硬问题。

## 三、安全的千篇一律

最隐蔽的一种：每一页都合乎规范，留白、细线、一种强调色、编辑式排版，但整套没有个性，换一个主题看起来也差不多。这是“有品味的模板”，本质上仍然是模板。我们自己的流程最容易产出这一种。

症状：

- 换一个主题，这套设计几乎不用改。
- 每一套演示都是同一种底色、同一种字体搭配、同一种安静。
- 没有一页让人记住。
- 整套的强度是一条平线，没有高潮。

改法：

- 视觉语言从主题里推导（`principles.md` 第 2 条），并在设计文稿里写明它从内容的哪个特征来。
- 样张阶段先做 2–3 个**截然不同**的方向放在一起比较，而不是直接深化第一个想到的方向。
- 指定签名画面，并真正给它们更多的打磨。
- 敢于用强烈的东西：满版的颜色、巨大的字、深色的整套、一张占满屏幕的图。克制是一种选择，不是默认值。

## 四、自检问题

每页渲染后问自己：

- 把内容换成另一个主题，这一页还能原样用吗？能，说明它是模板。
- 删掉哪个元素，信息完全不受影响？删掉它。
- 这一页的主角是什么？它是不是最先被看到的？
- 这是讲解页吗？不看讲稿，观众能从图上学到什么具体的东西？
- 有没有什么东西是“为了显得丰富”而加的？
- 整套放在一起：哪一页会被记住？如果答不出来，签名画面还不够强。
